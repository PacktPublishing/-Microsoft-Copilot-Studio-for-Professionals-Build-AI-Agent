# Lecture 19: How to Build Goal-Driven Agents With Persistent Memory Using the GitHub Copilot Harness

**In this folder:** Copilot-Studio-Credits-Setup-Steps.pdf, Goal-Driven-Agent-Instruction-Template.docx, Tool-Description-Quality-Checklist.docx, Launch-Readiness-Scenario-Pack-README.md, Test-Prompt-Set-Launch-Briefing-Agent.docx, Copy-Paste-Instruction-Block-Launch-Briefing.txt, Memory-Design-Worksheet.docx

Start with Copilot-Studio-Credits-Setup-Steps.pdf: goal-driven agents on the GitHub Copilot harness use Copilot Credits from the first build action, so the pay-as-you-go billing plan must be attached to your environment first. For Part 1, write the instructions with the Goal-Driven-Agent-Instruction-Template.docx (or paste from Copy-Paste-Instruction-Block-Launch-Briefing.txt), register tools using the Tool-Description-Quality-Checklist.docx, and test with Test-Prompt-Set-Launch-Briefing-Agent.docx. The Launch-Readiness-Scenario-Pack-README.md lists the exact sample files to use (launch plan, forecast, three Ridgeline emails, supplier agreement). For Part 2, use Memory-Design-Worksheet.docx and the two-run memory test in the prompt set.

## To follow along exactly
Have a Copilot Studio environment with the pay-as-you-go plan attached, and the Scenario Pack files from the Resources folder uploaded or connected (Planner plan, Excel workbook, Outlook messages, agreement and range brief).
