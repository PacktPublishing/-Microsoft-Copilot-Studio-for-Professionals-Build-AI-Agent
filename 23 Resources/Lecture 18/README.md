# Lecture 18: How to Test a Multi-Agent System Using End-to-End Business Scenarios

**In this folder:** Multi-Agent-End-to-End-Test-Pack-Template.docx, Multi-Agent-End-to-End-Test-Pack-Template.xlsx, Routing-Defect-Triage-Checklist.docx

Use the Multi-Agent End-to-End Test Pack Template to write your scenarios first (the Word version holds the failure modes, the four test flavors and the Pashun Sports scenarios S1 to S6; the Excel version is the working log with a defect tab and pass-rate summary). When a scenario fails, follow the Routing Defect Triage Checklist, fix the root cause (usually a child agent description or a missing input parameter), republish, and re-run the whole pack. No files from Resources/ are needed.

Have the Pashun Sports Project Support Helper with its three specialists (Customer Service Agent, Supplier Follow Up, Sales Reporter) connected.
