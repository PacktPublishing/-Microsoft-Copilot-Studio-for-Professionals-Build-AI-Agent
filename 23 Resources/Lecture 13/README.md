# Lecture 13: How to Choose the Right Model, Measure Agent Performance and Improve an Agent Using Usage Data

**In this folder:** Model-Selection-Decision-Matrix.xlsx, Model-AB-Test-Scorecard-Returns-Policy-Set.xlsx, Policy-Interpretation-Prompt.txt, Agent-Performance-Baseline-Tracker.xlsx, Stakeholder-One-Page-Agent-Report-Template.docx, Agent-Improvement-List-Template.xlsx, Agent-Metrics-Review-Checklist.pdf, Regression-Test-Script-for-Published-Agents.docx, Agent-Analytics-Review-Template.docx

For Part 1, fill in the Model Selection Decision Matrix, then run the five questions in the Model A/B Test Scorecard (Returns Policy Set) against the General and Deep models; the Policy Interpretation prompt is the copy-paste text for the prompt tool you scope to the Deep model. For Parts 2 and 3, record your first numbers in the Agent Performance Baseline Tracker, review with the Agent Analytics Review Template and the Agent Metrics Review Checklist, log improvements in the Agent Improvement List Template, summarize in the Stakeholder One-Page Agent Report Template, and re-test with the Regression Test Script for Published Agents.

Model names are examples only; they change often, so choose by category (General, Auto, Deep). The scorecard questions use `Resources/Pashun Sports – US Returns and Exchanges Policy.docx` and `Resources/Pashun Sports – US Delivery Timescales.docx`.

## To follow along exactly
Have your agent published (or run 10-15 varied test conversations first) and the returns policy connected as knowledge.
