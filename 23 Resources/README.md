# Microsoft Copilot Studio: The Complete Guide (2026) — Course Resources

This pack goes with the course script, which is also your written handout (it is attached to the lesson "Meet Pashun Sports T-Shirts and Download the Course Handout & Resource Pack"). Everything here follows the Pashun Sports T-Shirts story: the US launch of the Pashun Pro Tee, with Paul (founder), Jamie (project manager), Morgan (finance) and Ridgeline Apparel Supply (fabric supplier).

The **Resources** folder holds the shared sample data used in the demos: the four knowledge documents, the forecast workbook, the Ridgeline agreement, the supplier contacts list, list schemas, the launch plan and the sample emails. Each **Lecture** folder holds that lecture's worksheets, checklists, templates and copy-and-paste text, plus a short README that says which files to use and when. Files are not duplicated between folders.

## Start here

1. Open **Lecture 02** and follow the *Pashun Sports Setup Guide* to load the sample files into your own Microsoft 365 account.
2. Use the *Scenario Map* and *Resource Pack Contents Map* in the same folder to see how everything fits together.
3. Follow the lectures in order. Each Lecture README tells you what to open.

## What is not in the pack

- The importable Sales Reporter agent solution (Lecture 16). The *Sales Reporter Agent Rebuild Card* lists every setting so you can recreate it in about ten minutes.

## If you want to follow along in your own account

Extract the pack to a short top-level folder such as C:\PashunSports\ or ~/PashunSports/ rather than a deeply nested Downloads path, and keep the file names unchanged. You can also just watch the demos and use the files later; every "Your Turn" works equally well on your own real project and files.
