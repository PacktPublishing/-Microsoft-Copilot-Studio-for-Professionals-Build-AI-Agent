# Lecture 16: How to Design a Sales Reporter Agent Using Excel Data, Prompts and Tools

**In this folder:** Sales-Reporter-Design-Canvas.docx, Sales-Reporter-Prompt-and-Instructions.txt, Sales-Reporter-Test-Prompts.txt, Sales-Reporter-Agent-Rebuild-Card.docx

Plan with the Sales Reporter Design Canvas, then paste from Sales-Reporter-Prompt-and-Instructions.txt (name, routing description, instructions and the Excel tool description) and check your agent with Sales-Reporter-Test-Prompts.txt. The workbook is `Resources/Pashun-ProTee-US-Sales-and-Stock-Forecast.xlsx` (tables USForecast and SalesSummary).

Important: the lecture mentions a finished Sales Reporter agent solution you can import. The importable solution file is NOT included in this pack. Instead, Sales-Reporter-Agent-Rebuild-Card.docx lists every setting you need to rebuild the agent in about 10 minutes, so you can still follow the next lecture without doing the full build.

## To follow along exactly
Upload `Resources/Pashun-ProTee-US-Sales-and-Stock-Forecast.xlsx` to your team site and check each tab is formatted as a table.
