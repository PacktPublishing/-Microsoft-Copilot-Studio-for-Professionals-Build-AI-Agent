# Lecture 02: Meet Pashun Sports T-Shirts and Download the Course Handout & Resource Pack

**In this folder:** Pashun-Sports-Setup-Guide.docx, Pashun-Sports-Scenario-Map.docx, Resource-Pack-Contents-Map.docx, Prompt-Pack-Standard-Build-Prompts.docx, Prompt-Pack-Standard-Build-Prompts.txt

Start with Pashun-Sports-Scenario-Map.docx for the one-page picture of the people, files, systems and agents. Then follow Pashun-Sports-Setup-Guide.docx to load the sample data into your own Microsoft 365 account; it uses the four knowledge documents, the supplier contacts list, the Returns Log and Inbox Log schema files, the Launch Plan file and the Sample Emails from the shared Resources folder. Use Resource-Pack-Contents-Map.docx to find which file belongs to which lecture (the course script is your course handout). Finally, copy the starter prompt from Prompt-Pack-Standard-Build-Prompts.docx (or the .txt) and swap in your own placeholders for the exercise.

## To follow along exactly
Unzip the pack into a folder named Copilot Studio Course and have a Microsoft 365 work account ready that includes Teams, SharePoint, Outlook and Planner.
