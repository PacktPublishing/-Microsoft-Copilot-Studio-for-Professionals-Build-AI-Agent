# Lecture 20: How to Automate Deterministic Business Processes Using Workflows

**In this folder:** Deterministic-vs-Generative-Step-Classifier.docx, Inbox-Sort-and-Respond-Workflow-Build-Sheet.docx, Lecture-20-Copy-Paste-Text.txt

Use the classifier first to label each step of a process as generative or deterministic, then follow the build sheet step by step to create the Inbox Sort and Respond workflow, pasting the prompt text and JSON schema from Lecture-20-Copy-Paste-Text.txt. For testing, use the four emails in Resources / Sample Emails: Inbox-Test-01-Ridgeline-Delay.eml, Inbox-Test-02-Sizing-Question.eml, Inbox-Test-03-Refund-Request-150.eml and Inbox-Test-04-Newsletter.eml. The Inbox Log list schema is in Resources: Pashun Sports – Inbox Log (list schema and sample rows).xlsx. New mail can take several minutes to be picked up, so use Use a previous trigger event on the Activity tab to run on an existing email immediately.
